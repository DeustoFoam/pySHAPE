# Synthetic test particles

A fixed collection of synthetic particles for tests, examples and trying the interfaces. Binary STL, dimensionless coordinates. Generated by `examples/make_synthetic_assets.py` (NumPy only, fixed seeds); rerun it to regenerate them.

| File | Triangles | Purpose |
| --- | ---: | --- |
| `sphere.stl` | 5,120 | Sphere, radius 1 (5,120 triangles): S = I = L, sphericities close to 1. |
| `ellipsoid_3_2_1.stl` | 5,120 | Scalene ellipsoid, semi-axes 3, 2, 1, rotated and translated: principal dimensions, both ellipsoid methods. |
| `cuboid_4_2_1.stl` | 12 | Box 4 x 2 x 1 (12 triangles): exact box dimensions; inertia ellipsoid axes = sqrt(5/3) x sides. |
| `cube_subdivided.stl` | 768 | Cube of side 2 with subdivided faces (768 triangles): enough vertices for the fitted ellipsoid; non-unique PCA directions. |
| `regular_tetrahedron.stl` | 4 | Regular tetrahedron, edge 2*sqrt(2): non-unique PCA directions, exact minimum-volume box. |
| `torus_3_1.stl` | 3,072 | Ring torus, radii 3 and 1: non-convex, genus 1. |
| `rough_particle.stl` | 5,120 | Irregular, non-convex particle (seeded). |
| `two_spheres_overlapping.stl` | 2,560 | Two overlapping spheres (radii 1 and 0.6): a clump analysed as their solid union. |
| `open_ellipsoid.stl` | 1,088 | Ellipsoid with one end cut off (open surface): volume-based results unavailable; the preview shows the inner side through the opening. |
| `hollow_sphere.stl` | 2,560 | Sphere of radius 1 with a concentric spherical cavity of radius 0.5; both shells wound outwards in the file (cavities are found by nesting). cavities='keep': porosity 0.125; 'fill': solid sphere. |
| `cube_with_spherical_void.stl` | 2,048 | Cube of side 2 with an off-centre spherical cavity (radius 0.5, wound inwards in the file): the material centroid moves away from the void. |
| `sphere_with_two_cavities.stl` | 3,840 | Sphere of radius 2 with two separate spherical cavities (radii 0.5 and 0.4): n_cavities = 2. |
| `nested_island.stl` | 3,840 | Three concentric spheres (radii 3, 2, 1): with cavities='keep', a shell with a cavity containing a solid island (even-odd rule). |

Files with nested shells (`hollow_sphere`, `cube_with_spherical_void`, `sphere_with_two_cavities`, `nested_island`) are solids with cavities only with `cavities="keep"`; with the default `cavities="fill"` every shell is solid, as for the spheres of a clump.
