# pySHAPE validation

Scripts that reproduce the verification and validation of pySHAPE reported in
the accompanying article. All meshes are generated by [`meshes.py`](meshes.py),
which also contains the exact reference values; no external data are needed.

```bash
python -m pip install -e ".[mesh,analysis]"
python validation/run_benchmarks.py          # exact-solution benchmarks
python validation/export_crosscheck.py       # pySHAPE side of the comparison with SHAPE
```

| Benchmark (`run_benchmarks.py <name>`) | What is checked | Output |
| --- | --- | --- |
| `platonic` | Area, volume, Wadell sphericity, convexity and surface orientation tensor of the five Platonic solids against exact values; spread of PCA and minimum-volume box dimensions over 50 random rotations | `results/platonic_exact.csv`, `results/platonic_axes_rotation.csv` |
| `convergence` | Sphere and three ellipsoids (geodesic meshes with 80 to 327,680 faces) against exact area (elliptic integrals), volume, inertia, orientation tensor (quadrature) and axes | `results/convergence.csv` |
| `torus` | The ring torus of Table 3 of the SHAPE paper (Angelidakis et al., 2021) against theory, SHAPE and Meshlab | `results/torus.csv` |
| `union` | Spheres with satellites (solid union) against exact lens formulas, and the error of summing sphere volumes | `results/union.csv` |
| `indices` | Worked cuboid examples of Angelidakis et al. (2022) | `results/angelidakis_indices.csv` |
| `invariance` | Rotation, translation, scaling, vertex/face re-indexing and winding reversal of an irregular particle | `results/invariance.csv` |
| `performance` | Run time against mesh size | `results/performance.csv` |

## Cross-validation against the original MATLAB SHAPE

1. `python validation/export_crosscheck.py` exports 33 particles (Platonic
   solids, sphere and ellipsoids, the torus, multi-sphere particles and 20
   random irregular particles) to `validation/_work/*.mat`, after pySHAPE's
   own orientation and solid-union step, and stores the pySHAPE results in
   `results/pyshape_crosscheck.json`.
2. With a checkout of [SHAPE](https://github.com/vsangelidakis/SHAPE) and
   MATLAB (Image Processing Toolbox required by SHAPE):

   ```matlab
   addpath('validation')
   shape_crosscheck('<path to SHAPE>/Matlab', 'validation/_work', 'validation/results/shape_matlab.json')
   ```

3. `python validation/compare_crosscheck.py` writes `results/crosscheck.csv`
   (every particle and descriptor) and `results/crosscheck_summary.csv`.

For the SHAPE timings of the performance table, `run_benchmarks.py performance`
also exports geodesic spheres to `validation/_work_performance/`; run
`shape_crosscheck` on that folder with output
`validation/results/shape_performance.json`.

The committed `results/` were produced with pySHAPE 0.1.0 (Python 3.12,
NumPy 2.5, SciPy 1.18, trimesh 4.x, manifold3d 3.x) and SHAPE (last commit of
the MATLAB code, run in MATLAB R2024b) on Windows 11.
